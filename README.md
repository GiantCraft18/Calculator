# Простой веб-калькулятор

Это минималистичный, но полнофункциональный калькулятор, созданный с использованием **HTML**, **CSS** и **JavaScript**. Он работает в любом современном браузере и поддерживает как нажатие кнопок мышью, так и ввод с клавиатуры.

![Превью калькулятора](preview.png) *(замените на скриншот)*

## Возможности

- **Базовые операции**: сложение (+), вычитание (−), умножение (×), деление (÷), остаток от деления (%).
- **Умный ввод**: автоматическое форматирование чисел, обработка десятичных точек, ограничение длины ввода.
- **Отображение выражения**: показывает текущее вводимое выражение и результат.
- **Управление**:
  - `AC` — полный сброс.
  - `⌫` — удаление последнего символа.
  - `=` — вычисление результата.
- **Клавиатурная поддержка**: все кнопки дублируются клавишами (цифры, `+`, `-`, `*`, `/`, `%`, `Enter`/`=`, `Backspace`, `Escape`/`Delete`).
- **Адаптивный дизайн**: корректно отображается на мобильных устройствах и десктопах.

## Установка и запуск

1. **Скачайте** файл `index.html` (или скопируйте код).
2. **Откройте** его в любом браузере (Chrome, Firefox, Edge, Safari и т.д.).
3. Готово! Калькулятор сразу готов к использованию.

Никаких дополнительных зависимостей или серверов не требуется — всё работает локально.

## Использование

- **Нажмите на кнопки** мышью или тач-экраном.
- **Используйте клавиатуру**:
  - Цифры `0–9` и точка `.` для ввода чисел.
  - `+`, `-`, `*`, `/`, `%` для операций.
  - `Enter` или `=` для вычисления.
  - `Backspace` для удаления последнего символа.
  - `Escape` или `Delete` для полной очистки.

## Структура проекта

Проект состоит из одного файла `index.html`, который включает:

- **HTML** — разметка интерфейса.
- **CSS** — стилизация, тени, адаптивность.
- **JavaScript** — вся логика калькулятора (обработка нажатий, вычисления, обновление дисплея).

## Настройка

При желании вы можете легко изменить внешний вид:

- **Цвета**: отредактируйте значения `background`, `color` и `box-shadow` в CSS.
- **Размеры**: измените `padding`, `font-size` и `gap` у кнопок.
- **Поведение**: логика вычислений находится в функции `compute()` внутри тега `<script>`.
