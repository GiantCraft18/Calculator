## <span class="rainbow" style="font-size: 2rem; font-weight: 700;">🌟 Особенности</span>

- <span class="rainbow">**Базовые операции**: сложение (+), вычитание (−), умножение (×), деление (÷), остаток от деления (%)</span>
- <span class="rainbow">**Умный ввод**: форматирование чисел, десятичная точка, ограничение длины</span>
- <span class="rainbow">**Отображение выражения** — показывает текущее действие и результат</span>
- <span class="rainbow">**Управление**: `AC` (сброс), `⌫` (удалить символ), `=` (вычислить)</span>
- <span class="rainbow">**Клавиатурная поддержка**: цифры, операторы, `Enter`, `Backspace`, `Escape`</span>
- <span class="rainbow">**Адаптивный дизайн** — работает на любых устройствах</span>
